Quick, automated first-pass triage for a virtual screening library or a batch
of designed molecules — the kind of check a computational chemist runs before
handing a shortlist to the med-chem team.

It computes

| Category | Descriptors |

| Drug-likeness | Lipinski Rule-of-Five violations, QED |
| Synthesizability | Ertl & Schuffenhauer synthetic accessibility (SA) score |
| Assay liability | PAINS (pan-assay interference structure) alerts |
| Shape / rigidity | Rotatable bonds & fraction, Fraction Csp3, ring counts, Bertz complexity |
